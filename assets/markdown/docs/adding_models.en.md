# Add a new speech model

There are two ways to add a new speech model

## Add speech model from a file

1. Go to the settings page.
2. In the settings page, click on _"Add model"_.
3. In the _"Add model"_ page, first fill in a name for the speech model, through which you can recognize this model.
4. Click on the _"Load model"_ button.
4. In the file system, find the model file that you want to add and select it. This file must be of type _".asrmodel"_.

## Add speech model from a link

1. Go to the settings page.
2. Click on _"Add model"_.
3. In the _"Add model"_ page, first fill in a name for the speech model, through which you can recognize this model.
3. Paste the link of the model in the _"Model link"_ field.
4. In the file system, find the model file that you want to add and select it. This file must be of type _".asrmodel"_.
