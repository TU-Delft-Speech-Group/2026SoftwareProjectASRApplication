# Een nieuw spraakmodel toevoegen

Er zijn twee manieren om een nieuw spraakmodel toe te voegen.

## Spraakmodel toevoegen vanuit een bestand

1. Ga naar de instellingenpagina. 
2. Klik op _"Model toevoegen"_. 
3. Vul op de _"Model toevoegen"_ pagina eerst een naam in waaraan je het spraakmodel kunt herkennen. 
4. Klik op de knop _"Model laden"_. 
5. Zoek in het bestandssysteem het modelbestand dat je wilt toevoegen en selecteer deze. Dit bestand moet de extensie _".asrmodel"_ hebben.

## Spraakmodel toevoegen via een link

1. Ga naar de instellingenpagina. 
2. Klik op _"Model toevoegen"_. 
3. Vul op de pagina _"Model toevoegen"_ eerst een naam in waaraan je het spraakmodel kunt herkennen. 
4. Plak de link naar het model in het veld _"Model link"_. 
5. Klik op _"Model laden"_ om het model te downloaden en toe te voegen.
